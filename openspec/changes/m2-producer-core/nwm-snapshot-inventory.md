## 5. 枚举与闭包的再生方法

本清单的所有符号枚举可用下列命令在 pin 上机械复算（`<NWM>` = NWM 仓路径，`8ae9b8f2` = 锚点）：

- 计数型枚举：`git -C <NWM> grep -n '<pattern>' 8ae9b8f2 -- <path>`（清单内已给出 pattern 与命中总数的行，直接对比即可）。
- 抽取式行的闭包：把 `git -C <NWM> show 8ae9b8f2:<path>` 的输出交给 `ast` 解析，取模块级 `FunctionDef`/`ClassDef` 建名字→行号表，从抽取种子出发按 `ast.Name` / `self.<attr>` 引用做广度优先传递闭包，直到不再新增；`剥离点` 与闭包的交集即"必须改写而非直接搬运"的点（如 `_runtime_command`、`FakeHydroRunRepository`、`repository=` 形参）。
