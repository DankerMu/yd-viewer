# NWM@8ae9b8f2 快照勘察清单

锚点 commit：`8ae9b8f29c8b72c574e8cbd95f2994160bd42832`（公开仓 DankerMu/SHUD-NWM `origin/master`，design.md D2）。

每个快照文件（含测试）头部必须写溯源头，格式固定为：

```text

```

勘察方式：只读 git plumbing（`ls-tree` / `show` / `cat-file -e` / `grep`）读 pinned commit，未触碰 NWM 工作树（agent-ops §5）。

目标布局遵循 design.md D1：全部落 `producer/src/yd_producer/<module>/<file>.py`，测试落 `producer/tests/<file>.py`。

清单约定（五条，全表适用；每条对应 §5 的一个机械检查）：

1. **枚举必须可机械再生。** `剥离点` / `抽取` / `备注` 里的符号枚举，要么写全集，要么给出再生该集合的 grep 命令并标注命中总数。不出现无标记的截断列表。
2. **抽取式行必须给传递闭包，闭包义务含模块级常量。** 标注「抽取式」的行，其 `抽取` 列包含被抽取符号直接或间接调用的全部私有 helper、异常类型**与模块级常量**（含模块级 `X = <expr>` 重绑定，如测试文件顶部的 `X = module.X` import shim），逐个给定义行号；闭包被主动切断处（如改写为显式入参）明确写出切点。模块级常量此前被漏在闭包义务之外，是 Round 2 的根因：§5 原再生方法的名字表只取 `FunctionDef`/`ClassDef`，按它复算永远显示通过。
3. **规范性动作只能写在 `剥离点` 列。** 删除 / 改写 / 内联 / 替换 / 改抛这类落码必须执行的动作，一律写进 `剥离点`；`备注` 只放理由、保留集与语义锚点，不得独家承载动作。`剥离点` 写 `无` 的行必须真的零动作。（抽取式行的 `抽取` 列是本约定的例外：它按约定 2 是规范性的。）
4. **跨行引用必须闭合。** 任一行命令删除的符号，若被**其他行保留的内容**在 pin 上引用，则该其他行必须点名处置（删该用例 / 改写 / 内联字面量 / 保留并说明）；处置产生的覆盖缺口一律在 §4 声明。逐行修某一行的删除集时必须回头扫引用方，否则缺陷会以跨行形状复发。
5. **符号与行号必须与 pin 的 ast 一致。** `` `符号`(Lnnn) `` 的 `Lnnn` 等于该符号的 ast `lineno`；`` `符号`(Lnnn-mmm) `` 等于 `(lineno, end_lineno)`；类成员须写成 `` `类名.方法名` `` 以免被读成模块级符号；非定义点的行号（实例化点、调用点、断言点）须显式标注是哪一种。
